A small vocabulary
FN 00 … END
Define function 0. Functions use consecutive indices.
PAR 00 · LOC 01 · RES
Declare a parameter, local or result. All default to i32.
GET 00 · SET 00 · TEE 00
Read, write, or write and keep a local value.
CONST 42 · ADD · RET
Push a value, add two stack values, return.
LPAR · LRES · LCONST · LADD
Prefix L for i64, F for f32, D for f64. GET/SET use the declared local type.
BLOCK · LOOP · IF · ELSE · END
Structured control flow. Add I32, I64, F32 or F64 for a block result.
BR 0 · BRIF 1 · CALL 00
Branch by relative block depth, or call a function. Depth 0 is the innermost label.
MEM 1 4 · LOAD · STORE
Declare initial / maximum pages. Optional memory arguments: offset, alignment exponent.
GLB 00 7 · GGET 00 · GSET 00
Declare, read and write a mutable global. Type prefixes also apply to GLB.
EXP "add" 00
Export a function by name. Unnamed functions get an automatic fn00-style export.

Numbers & bytes
Numbers are decimal, including 00. Use 0x2A for hexadecimal. Offsets and byte values in the viewer are hexadecimal. Integers use signed LEB128 for constants, unsigned LEB128 for indices and lengths.
What this version covers
Four numeric types; scalar arithmetic, comparisons and conversions; locals, globals, calls, blocks, loops, branches and a single memory. The instruction catalog below is generated from the assembler rule table.
Stepping executes decoded WASM in a reversible interpreter. Native run runs a fresh instance of the same binary in the browser engine, with a two-second timeout. It does not change the debugger state.
WASM import retains the exact uploaded bytes for supported modules. Imports, tables, start functions, SIMD, references, GC and multi-value signatures are outside this version. Memory requires an explicit maximum of at most 256 pages; the debugger keeps the last 2,000 reversible steps. NaN payload bits are not preserved by the interpreter.
